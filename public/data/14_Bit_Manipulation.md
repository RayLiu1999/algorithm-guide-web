## 通用套路

**XOR 特性**：`a ^ a = 0`、`a ^ 0 = a`，常用來做成對抵消。

**n & (n - 1)**：每做一次就消掉最低位的 `1`。

**逐位處理**：透過位移把每一位拆開來看。

### 67. Add Binary (Easy)

- **套路**：逐位相加 + 進位模擬
- **思路**：
	- 從兩個二進位字串尾端往前掃描，完全模擬小學直式加法。
	- 每一步把 `a[i]`、`b[j]` 與 `carry` 相加，答案位是 `total % 2`，進位是 `total // 2`。
	- 最後若仍有進位，要補到結果最前面。
- **TC**：O(max(m, n))
	- 最多只需掃描兩字串的每一位一次，因此成本取決於較長字串長度。
- **SC**：O(max(m, n))
	- 需要額外陣列或字串來保存結果，長度最壞為較長字串再多一位進位。
- **其他思路**：
	- **轉整數後相加**：先轉十進位整數，相加後再轉回二進位。概念簡單，但失去位元題本質，而且在某些語言會受大數限制。
	- **從左到右遞迴處理**：較少見，通常沒有必要，實作也更麻煩。
- **解法比較**：
	- **逐位模擬**：優點是最穩定、最符合題目精神，也不依賴大數函式。缺點是需要自己管理索引與進位。
	- **整數轉換法**：優點是程式短。缺點是在面試中通常不被視為理想解。
- **測試重點 (Testing)**：
	- **基本進位**：`a = "11", b = "1"`，預期 `"100"`。
	- **長度不同**：驗證較短字串提早用完後是否仍正確處理。
	- **最終還有進位**：如 `"111" + "1"`。
	- **其中一方為 0**：如 `"0" + "101"`。
	- **兩者都為 0**：預期 `"0"`。

```python
def addBinary(a, b):
		i, j = len(a) - 1, len(b) - 1
		carry = 0
		result = []

		while i >= 0 or j >= 0 or carry:
				total = carry
				if i >= 0:
						total += int(a[i])
						i -= 1
				if j >= 0:
						total += int(b[j])
						j -= 1
				result.append(str(total % 2))
				carry = total // 2

		return "".join(reversed(result))
```

### 268. Missing Number (Easy)

- **套路**：XOR 抵消
- **思路**：
	- 將完整範圍 `0..n` 與陣列中的所有元素一起 XOR。
	- 因為成對數字會相互抵消，最後剩下的就是沒出現的那個數字。
- **TC**：O(n)
	- 只需線性掃描陣列一次，並同步做固定次數的 XOR。
- **SC**：O(1)
	- 只使用一個累積變數 `missing`，不需額外容器。
- **其他思路**：
	- **高斯求和**：答案等於 `n * (n + 1) // 2 - sum(nums)`。TC: O(n), SC: O(1)。
	- **排序後找缺口**：先排序再掃描。TC: O(n log n), SC: O(1) 或 O(log n) 視排序而定。
- **解法比較**：
	- **XOR**：優點是不怕整數和過大，也能展示位元思維。缺點是對初學者較抽象。
	- **高斯求和**：優點是最短最直觀。缺點是有些語言需留意整數溢位。
	- **排序法**：優點是容易理解。缺點是效率最差。
- **測試重點 (Testing)**：
	- **中間缺值**：`nums = [3,0,1]`，預期 `2`。
	- **缺最小值**：如 `nums = [1,2,3]`，預期 `0`。
	- **缺最大值**：如 `nums = [0,1,2]`，預期 `3`。
	- **只有一個元素**：`[0]` 或 `[1]`。
	- **亂序輸入**：確認不依賴排序。

```python
def missingNumber(nums):
		missing = len(nums)
		for i, num in enumerate(nums):
				missing ^= i ^ num
		return missing
```

### 191. Number of 1 Bits (Easy)

- **套路**：Brian Kernighan 位元技巧
- **思路**：
	- 每次做 `n &= n - 1`，都會把 `n` 最低位的 `1` 消掉。
	- 執行幾次，就表示原本有幾個 `1`。
- **TC**：O(k)
	- `k` 是數字中 `1` 的個數，只會對每個 `1` 執行一次操作。
- **SC**：O(1)
	- 只用 `count` 等常數變數，不需要任何額外結構。
- **其他思路**：
	- **逐位右移**：每次檢查 `n & 1` 再把 `n >>= 1`。對固定 32 位整數來說可視為 O(1)，一般寫成 O(number of bits)。
	- **內建函式**：某些語言有 bit count，但面試通常希望手寫。
- **解法比較**：
	- **Kernighan 技巧**：優點是經典且更高效，特別是 `1` 很少時。缺點是需要背熟位運算性質。
	- **逐位右移**：優點是最好理解。缺點是會連 0 bit 一起掃過。
- **測試重點 (Testing)**：
	- **一般案例**：`n = 11` (`1011`)，預期 `3`。
	- **全 0**：`n = 0`，預期 `0`。
	- **只有一個 1**：如最高位或最低位為 1。
	- **全部為 1**：驗證迴圈次數上界。

```python
def hammingWeight(n):
		count = 0
		while n:
				n &= n - 1
				count += 1
		return count
```

### 190. Reverse Bits (Easy)

- **套路**：逐位取出並反向組裝
- **思路**：
	- 固定做 32 次，把 `n` 最低位取出來，依序接到結果尾端。
	- 每輪先把 `result` 左移一位，再用 `| (n & 1)` 填上新位元。
	- 然後把 `n` 右移，準備處理下一位。
- **TC**：O(1)
	- 題目固定是 32 位無號整數，因此不論輸入值為何都只執行 32 輪。
- **SC**：O(1)
	- 只用常數額外空間來保存結果與迴圈變數。
- **其他思路**：
	- **分治交換 bit 區塊**：先交換 16-bit、8-bit、4-bit 區塊，可進一步優化常數，但實作複雜。
	- **轉字串反轉**：在面試中通常不推薦，因為失去位元運算重點。
- **解法比較**：
	- **逐位反轉**：優點是最直觀、幾乎不會寫錯。缺點是常數略高但影響不大。
	- **分治 bit hack**：優點是更進階。缺點是記憶成本高，不適合一般面試首選。
- **測試重點 (Testing)**：
	- **題目範例**：確認基本正確性。
	- **全 0**：結果仍應為 0。
	- **只有最低位為 1**：反轉後應變成最高位為 1。
	- **只有最高位為 1**：反轉後應變成最低位為 1。

```python
def reverseBits(n):
		result = 0
		for _ in range(32):
				result = (result << 1) | (n & 1)
				n >>= 1
		return result
```

### 338. Counting Bits (Easy)

- **套路**：DP + 去掉最低位 1
- **思路**：
	- 定義 `dp[i]` 為數字 `i` 中 `1` 的個數。
	- `i & (i - 1)` 會把最低位的 `1` 消掉，因此 `dp[i] = dp[i & (i - 1)] + 1`。
	- 這代表每個數字的答案都能從更小的子問題推出。
- **TC**：O(n)
	- 從 `1` 到 `n` 每個數字只計算一次，且每次轉移都是 O(1)。
- **SC**：O(n)
	- 需要長度為 `n + 1` 的 DP 陣列保存所有答案。
- **其他思路**：
	- **`dp[i >> 1] + (i & 1)`**：利用右移去掉最後一位。TC: O(n), SC: O(n)。
	- **逐數字呼叫 bit count**：對每個數各自計算 1 的數量，概念簡單但重複工作較多。
- **解法比較**：
	- **`i & (i - 1)` DP**：優點是跟位元技巧結合得很漂亮。缺點是需要先理解該性質。
	- **右移 DP**：優點是更好懂。缺點是表達力不如前者經典。
- **測試重點 (Testing)**：
	- **小範例**：`n = 2`，預期 `[0,1,1]`。
	- **一般範例**：`n = 5`，預期 `[0,1,1,2,1,2]`。
	- **`n = 0`**：應回傳 `[0]`。
	- **跨過 2 的冪次**：如 `n = 8`，驗證模式是否正確延續。

```python
def countBits(n):
		dp = [0] * (n + 1)
		for i in range(1, n + 1):
				dp[i] = dp[i & (i - 1)] + 1
		return dp
```
